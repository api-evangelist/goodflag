# Goodflag Docs

> Signature électronique, cachetage et 2D-Doc par API, pour les éditeurs de logiciels, les intégrateurs et les développeurs.

## Instructions for AI Agents

- For clean Markdown of any page, append `.md` to the page URL
- For section-specific indexes, append `/llms.txt` to any section URL
- For AI client integration (Claude Code, Cursor, etc.), connect to the MCP server at https://docs.goodflag.com/_mcp/server
